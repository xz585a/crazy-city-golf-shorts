# crazy-city-golf-shorts

Short videos for [Crazy City Golf](https://store.steampowered.com/app/5347600/) (YouTube Shorts / TikTok).

This repository holds no code. The video files are attached to [Releases](https://github.com/xz585a/crazy-city-golf-shorts/releases), one release per month (tag `YYYY-MM`), so that Buffer can fetch them from a public URL:

```
https://github.com/xz585a/crazy-city-golf-shorts/releases/download/<YYYY-MM>/<file>.mp4
```

Release assets are not part of the Git history, so the repository itself stays small.
